## 图的主线

**政策与收益构成 → 甘肃能源/网架特征 → 利润形成与问题诊断 → 可落地措施与市场空间**。

核心经营判断：甘肃独立储能不是简单的“省级平均价差市场”，而是由**节点价格、调度调用、设备性能、可靠容量履约和结算治理**共同决定收益。当前受访项目中，调频辅助服务仍是主要市场化收入，现货更多承担 SOC 管理和节点性机会收益，可靠容量补偿提供新增政策价值，但需要持续跟踪实际分摊与到账。
